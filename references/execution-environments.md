# 零本地安装与执行环境路由

只在正式分析需要选择计算环境、依赖或联网服务时读取。核心原则是：用户提供数据与必要决策，Codex 负责执行和交付；不得把环境搭建变成用户的手工作业。

## 1. 优先级

1. 使用当前任务已经存在的 Python、R、CLI、MCP、数据库接口、已安装 Skill 与包。
2. 若产品当前确实支持托管/云端执行或任务委派，且数据访问与授权条件满足，可把计算放到该环境。
3. 如需依赖，只能安装在 Codex 可控的沙箱、容器、临时目录或隔离环境；记录来源、版本、锁文件和执行路径，不写入用户 Windows 主机的全局或用户级环境。
4. 若首选包不可用，使用经验证的等价实现。等价性至少覆盖设计矩阵、缺失处理、效应方向、方差估计、多重校正和结果列语义；在 manifest 中记录偏差与验证。

不得要求用户自行安装 Python、R、RStudio、Bioconductor、Rtools、Conda、Docker 或某个分析包。只有用户明确请求安装指导时，才单独解释安装方案；这不改变当前分析仍应优先零本地安装完成。

## 2. 本地路径与云端事实边界

- 当前本地任务能读取的 `C:\...`、`D:\...` 等绝对路径，可按只读输入处理；路径必须原样引用并支持空格与中文。
- 云端或远程任务通常不能自动读取本机盘符。调用前必须验证数据可见性；不可见时明确告诉用户，并仅请求上传、授权或传输分析所需的最小文件集。
- 不把“路径已记录”写成“文件已读取”。存在、可读、大小和校验和分别记录。
- 不把上传成功等同于内容完整；可行时比较上传前后大小与 SHA-256。

## 3. 隐私与外部服务

- 官方数据库查询若只需蛋白/基因 ID，只发送去重后的必要 ID 和物种参数。
- 不为富集、作图或统计向第三方上传完整私有定量矩阵。
- 大规模 ID、原始质谱、临床/品系敏感信息或未公开数据若必须提交第三方，先说明目的、范围、服务方和替代方案，等待授权。
- 记录服务 URL/名称、版本或访问日期、查询参数、提交数量、返回数量、失败重试和缓存文件。

## 4. 无可用计算环境

当所有安全路径均不可用时，输出以下事实，而不是伪造结果：

1. 当前任务缺少哪类计算能力或数据可见性。
2. 已验证过哪些候选路径及失败证据。
3. 可继续的非计算工作，例如输入审计、数据字典、计划、查询清单和目录初始化。
4. 最小恢复方案：托管运行、授权上传或转移必要文件、等待服务恢复。

不得以“请在本地运行以下长脚本/安装以下环境”作为默认交付。用户未授权环境变更时，停在可验证的部分完成状态。

## 5. 失败与降级记录

每个失败分支写入 `logs/run_log.jsonl`，至少含 UTC 时间、阶段、环境、操作、输入摘要、错误、重试、替代方案和最终状态。可靠替代仍失败时，保留部分结果并在工作簿 README、中文报告和运行时审计中保持一致的 `FAILED` 或 `NOT_RUN` 状态。
